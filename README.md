# AI 应用开发 · 零基础通关手册

一份写给**编程零基础**的人的 AI 应用开发教材。从「JSON 是什么」讲到「评测、可观测性、Agent、RAG」。

不用装任何东西，打开就能读。

---

## 这是什么

**33 章 + 4 个附录**，全部装在一个 HTML 文件里（268 KB）。

- 左侧章节目录，点哪章跳哪章，滚动自动高亮
- 顶部阅读进度条
- 手机端适配（右下角按钮打开目录）
- 纯静态，不联网、不装依赖、不开服务器

关于页面的完整介绍见 [`说明.md`](说明.md)。

---

## 适合谁

- 会一点编程（哪怕只学到循环），想做 AI 应用但不知道从哪下手
- 看过很多 AI 教程，但「术语都认识、连起来就不会」
- 想做出**能交给别人用**的东西，而不是永远停在 demo

## 目录结构

```
第一部分 · 地基（1–4）      网页 / 程序 / JSON / 前后端全貌
第二部分 · 前端（5–8）      HTML / CSS / JS / 第一次连接前后端
第三部分 · 后端（9–12）     Python / FastAPI / 数据库 / 登录
第四部分 · 多用户（13–15）  数据隔离 / WebSocket 与 SSE / 并发
第五部分 · AI 基础（16–19） LLM 原理 / 提示词工程 / 上下文工程
第六部分 · AI 应用（20–30） 调模型 / 流式 / 工具调用 / Agent / RAG / MCP
                            模型选型 / 评测 / 可观测性 / 多模态 / 本地模型
第七部分 · 上线（31–33）    调试 / 部署 / 安全
附录 A–D                   名词词典 / 学习路线 / 报错表 / 15 个练手项目
```

每一章都是同一个结构：**先用比喻讲「这是什么」→ 给出它的名字 → 一个能跑的例子 → 一句话总结**，并且都有一个动手任务。

---

## 几个特点

**① 术语先讲后用。** 每个词第一次出现时先用人话解释，后面才拿来用。

**② 有 34 个动手任务。** 每个都是几分钟能跑起来的小东西，不是「请自行练习」。

**③ 讲了三样外面教程普遍不讲的：**
- 第 27 章 **评测（Evals）** —— 改了提示词，怎么知道变好还是变坏
- 第 28 章 **可观测性** —— AI 应用「静默失败」时怎么查
- 第 30 章 **本地模型** —— 结合 8GB 显存的实际情况讲
